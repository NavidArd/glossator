# Changelog

## 1.0.0

The first public release.

- Write or circle on the page with the pen; an AI answers in the margin in handwriting, with typeset math.
- Conversations in the note: follow-ups written on a pad or typed.
- Claude with an Anthropic key; Gemini, GPT, Grok, Mistral, Qwen and more with an OpenRouter key.
- Writing toolbar: pen widths, pencil, marker (real highlights), precise eraser, lasso, undo and redo.
- Palm rejection with Ink Away's pen bridge; wrist touches don't turn pages while writing.
- AI notes in KOReader's Export highlights (Readwise, Joplin, Nextcloud Notes, Markdown and more).
- Reading look: one whole PDF page per screen, top bar, progress bar, tap zones, cover on the sleep screen.
- Certificate-checked HTTPS for API requests.
- Install with KPM.
